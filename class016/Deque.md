## 数组实现
k指的是数组长度
使用 size，l，r 三个变量，刚刚开始 l = r = 0 
## size 控制满还是没满
### 尾入：  r != k - 1 时候， 放入 r + 1 位置，然后 r++；  
当 r = k - 1， 放入 0 位置， r = 0

### 头入： l ！= 0 , 放入 l - 1, l--
l == 0 放入 ， k - 1， l = k - 1

### 尾出
弹出R 位置 然后 r --  
如果 r = 0 r = k - 1


### 头出
